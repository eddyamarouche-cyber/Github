# Italy GTM Strategy — Executive Deck

Interactive 6-slide interview presentation distilled from the Italy GTM take-home assignment.

**Narrative:** Focus on the right industries, sell trusted AI to C-level executives through partners, land with Engineering Productivity, expand into Enterprise AI, and use flagship customers to scale Anthropic across Italy.

## Slides

1. **Focus** — Mission, why Italy, three priority verticals, core positioning  
2. **Verticals** — Financial Services, Manufacturing, Energy & Utilities  
3. **Go-To-Market** — Tier-1 focus, pipeline mix, multipliers  
4. **Land & Expand** — Claude Code → Claude Enterprise → Trusted AI Platform  
5. **UniCredit** — Example account path  
6. **Why Me** — Experience, value, vision  

## Start

```bash
cd italy-gtm
npm install
npm run dev
```

Open the local URL shown in the terminal (typically `http://localhost:5173`).

## Navigation

| Control | Action |
|--------|--------|
| ← / →, Space, Page Up / Down | Previous / next slide |
| 1–6 | Jump to slide |
| Home / End | First / last slide |
| Dots / top numbers | Jump to slide |

## Content

Edit copy in [`src/data/slides.ts`](src/data/slides.ts).

## Build

```bash
npm run build

```
